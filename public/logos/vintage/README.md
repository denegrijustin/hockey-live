# Vintage NHL logos

65 earliest primary logos for the current and historical NHL team entries listed by [SportsLogos.Net](https://www.sportslogos.net/teams/list_by_league/1/National-Hockey-League-Logos/NHL-Logos/), collected October 23, 2026.

Original image files are preserved unchanged. Former team names are separate entries; shared designs may predate a name change or NHL entry. `manifest.json` lists each team's era, logo seasons, local asset URL, and original source links. Asset URLs start with `/logos/vintage/`.

Credit: Chris Creamer's SportsLogos.Net. Logo rights belong to their respective owners.
